# Godot Tetris in C#

This is a complete Tetris game built using Godot 4.2.2 with C# logic.

## Features
* Classic Tetris gameplay
* Seven classic tetrominoes (I, J, L, O, S, T, Z) with accurate colors
* Movement, fast drop, and rotation
* Line clearing with scoring
* Increasing speed as lines are cleared
* Game over detection

## How to run
Make sure you have Godot 4 (Mono/C# version) installed.
1. Open Godot and import the `Tetris` folder.
2. Build the C# solution.
3. Press play!

Controls:
* Left/Right arrow keys: Move piece
* Down arrow key: Fast drop
* Up arrow key: Rotate piece
